## خلاصه‌ی صادقانه‌ی وضعیت

این ۲۶ فایل «طرح فنی + اسکلت کد کارکردی» هستند، نه فیچر production-ready کامل.
یعنی:

- مدل داده، منطق کسب‌وکار اصلی (پارسرها، موتورهای rule-based) و API هر ۲۶ ایشو
  نوشته و اجرا شده‌اند (`backend/`)، و بخش‌های الگوریتمی با pytest تست شده‌اند
  (۱۲ تست سبز، بدون نیاز به دیتابیس).
- UI وب برای مهم‌ترین صفحات (`frontend/`) نوشته شده ولی build/run نشده (نیاز به
  `npm install` روی سرور، نه داخل این محیط).
- سه مورد صراحتاً ناتمام‌اند و نیاز به تصمیم/کار جدا دارند: اتصال WhatsApp (#۶)،
  اتصال فرم لندینگ به API لید (#۸)، و ساخت واقعی اپ موبایل (#۲۲؛ نیازمند تصمیم
  استک React Native/Flutter).
- migration واقعی دیتابیس (Alembic) باید روی سرور با PostgreSQL در حال اجرا انجام
  شود، نه داخل این محیط ابزار.
