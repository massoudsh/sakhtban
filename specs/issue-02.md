# Issue #2 — پارسر NLP فارسی برای گزارش‌های آزاد

> فاز ۰ — Wedge MVP · [GitHub Issue #2](https://github.com/massoudsh/sakhtban/issues/2)

## مسئله

گزارش‌های کارگاهی فارسی متن آزاد و غیرساخت‌یافته‌اند؛ باید فعالیت، مقدار، موقعیت و علت تأخیر از آن‌ها استخراج شود.

## طرح فنی

نسخه‌ی MVP heuristic (regex + کلیدواژه) است، نه مدل ML — تا بدون داده‌ی آموزشی و زیرساخت GPU هم قابل اجراست. جمله‌بندی متن به جمله‌های کوتاه شکسته می‌شود و هر جمله برای الگوهای موقعیت (`طبقه/بلوک/زون`)، مقدار+واحد، و کلیدواژه‌ی تأخیر بررسی می‌شود. طراحی به‌گونه‌ای است که `extract_entities` بعداً با یک مدل NER فارسی جایگزین شود بدون تغییر در contract تابع.
