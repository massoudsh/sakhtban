## طرح فنی

اپ موبایل بومی (React Native/Flutter) در scope این فاز از backend نیست — نیازمند تصمیم جدا درباره‌ی استک موبایل است. آنچه آماده است: API کامل مصرفی برای اپ موبایل (`POST /qa/defects` با عکس/GPS/موقعیت/شدت) و schema اعتبارسنجی آن. تا زمان ساخت اپ، فرم وب معادل (صفحه‌ی گزارش) برای تست API استفاده می‌شود.

## فایل‌های کد مرتبط

- `backend/app/schemas/qa.py (DefectCreate)`

## وضعیت

API کامل و آماده مصرف؛ اپ موبایل واقعی نیاز به تصمیم استک و توسعه‌ی جدا دارد.
